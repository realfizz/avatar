# avatar

💎 Dithered avatars as a microservice

## Usage

```
http://localhost:3000/fizz
```

You get a PNG, 120×120.

### Roundness

```
http://localhost:3000/fizz?rounded=60
```

### Size

```
http://localhost:3000/fizz?size=32
```

### SVG

```
http://localhost:3000/fizz?format=svg
```

## Run

```bash
bun run dev
```
